# Video to MP3 (Android APK)

1. Create a free GitHub account and a new repository.
2. Upload ALL files from this folder (keep the .github folder).
3. Go to the Actions tab > "Build APK" > Run workflow.
4. When it finishes (about 5-8 minutes), download "video-to-mp3-apk" from the run page, unzip it, and install app-debug.apk on your phone.
